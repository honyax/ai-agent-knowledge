# Claude Sonnet 4.6リリース & API主要変更 — 実験ノート

> ローカル実行なし。リリースノート精読・考察のみ（2026-03-30、Claude Code Web）

## 主要変更点の整理

### モデル
- `claude-sonnet-4-6` が現行推奨モデル
- コーディング・エージェント・専門業務でフロンティア性能
- 1Mトークンコンテキストウィンドウ（ベータ）

### API変更
| 機能 | 変更内容 |
|------|---------|
| Web Search | betaヘッダー不要でGA |
| Tool Calling | betaヘッダー不要でGA |
| Structured Outputs | `output_format` → `output_config.format` に移動 |
| Data Residency | `inference_geo` パラメータ追加 |
| コード実行ツール | web search/fetch 併用時に無料化 |

## ゲーム開発への応用メモ

- **カードゲームAI**: `claude-sonnet-4-6` でモデルID更新
- **デッキ構成の構造化出力**: `output_config.format` + JSON Schemaで安定化
- **メタゲーム分析**: Web Search GAで外部情報取得が簡単に
