## 7レイヤー現状評価

### 1. CLAUDE.md

**状態**: グローバル（`~/.claude/CLAUDE.md`）とプロジェクト（`CLAUDE.md`）の両方が存在。

**グローバルCLAUDE.md評価**: 黄金律に完全準拠。
- 言語設定（日本語）
- AskUserQuestion の使用指示
- 絵文字ポリシー
→ いずれもコードから推論不可能な設定のみ記載。問題なし。

**プロジェクトCLAUDE.mdの黄金律チェック**:

「ディレクトリ構成」「エントリのステータス管理」の2セクションは、
一見「コードから読み取れる」ように見えるが、以下の理由で**残すべき**と判断した:

- `エントリのステータス管理` → テンプレートファイル（`templates/`）には記載がない。
  AIがエントリのフロントマターから推察するには複数ファイルのサンプリングが必要でコストが高い。
- `ディレクトリ構成` → `ls` で確認できるが、各ディレクトリの役割（特に `experiments/`
  の位置づけ）はファイル構造だけでは分からない。明示することでAIの文脈理解コストを削減できる。

**結論**: このリポジトリの規模と性質上、現在の情報量は適切。
黄金律は「コードから読み取れるものを書かない」という原則だが、
「読み取りコストが高いもの」は書いておく価値がある。

**settings.local.json（実施前）**:
特定の操作に対する許可が蓄積しており、以下の残骸が存在していた:
- `Bash(rm "d:/var/git/.../commands/...")` — コマンドディレクトリ削除の残骸
- `Bash(rmdir "d:/var/git/.../commands")` — 同上
- `Bash(mv RESULT.md 2026-03-24-bare-flag-effort.md)` — 過去の実験ファイル移動
- `Bash(rm README.md)` — 過去のファイル削除

**実施した変更**: 特定パス指定のある残骸を削除。以下を残した:
- `WebFetch` — 汎用的なWeb取得許可
- `Read(//c/Users/honya/.claude/**)` — Claude設定ファイルの読み取り
- `Bash(echo "EXIT: $?")` — フック用の汎用コマンド
- `Bash(for f:*)`, `Bash(do echo:*)`, `Bash(done)` — シェルループ汎用
