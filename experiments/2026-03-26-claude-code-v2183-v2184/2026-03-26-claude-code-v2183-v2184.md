## 各機能の確認

### managed-settings.d/（v2.1.83）

`~/.claude/managed-settings.d/` が存在しないことを確認。
ディレクトリを作成すれば、設定フラグメントをアルファベット順にマージする機能が使える。
個人利用では恩恵は限定的だが、複数プロジェクトで異なるHooks設定を共存させたい場合に有用。

使い方イメージ:
```
~/.claude/managed-settings.d/
├── 00-base.json         # 基本設定
├── 10-hooks.json        # Hooks設定
└── 20-mcp.json          # MCP設定
```

### CwdChanged / FileChanged フック（v2.1.83）

現在の ~/.claude/settings.json には hooks 設定なし。
CwdChanged フックを使えば、ディレクトリ移動時に自動で環境変数をセットするようなことが可能。

設定例（将来的に追加候補）:
```json
{
  "hooks": {
    "CwdChanged": [
      {
        "matcher": "d:/var/git/my-unity-project",
        "hooks": [{ "type": "command", "command": "echo 'Unity project loaded'" }]
      }
    ]
  }
}
```

### PowerShell ツール（v2.1.84）

Windows向けopt-inプレビュー。`--help` にはフラグとして出てこない。
settings.json の設定キーは公式 changelog 要確認。
有効化すれば Bash ツールの代わりに PowerShell が使えるようになり、
Windows パス（`C:\...`）やPowerShellネイティブコマンドが通りやすくなる。

### トランスクリプト検索（v2.1.83）

セッション内で `Ctrl+O` → トランスクリプトモード → `/` で検索、`n`/`N` でナビゲート。
機能自体は実装済みのはず（バージョン確認済み）。
特に長いセッションで「あの返答どこだっけ」を探す時に便利。

### セキュリティ: ENV_SCRUB（v2.1.83）

`CLAUDE_CODE_SUBPROCESS_ENV_SCRUB=1` を環境変数に設定すると
サブプロセスから認証情報（API キー等）を除去できる。
設定していないが、セキュリティ意識として把握しておく価値あり。
