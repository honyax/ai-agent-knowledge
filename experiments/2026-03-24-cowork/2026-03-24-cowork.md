# 実践ログ: Claude Cowork

## 実施内容

エントリで把握した機能の確認として、unread フォルダのエントリ一覧をスプレッドシート形式に整理してもらった。
実際にCoworkを起動してファイルシステムへのアクセスと一覧生成を試した。

## 結果

- unread フォルダのファイル一覧をスプレッドシート（表形式）として出力できることを確認
- ローカルファイルへのアクセスと構造化出力は問題なく動作

## 観察メモ

- 単純なファイル一覧・整理タスクは動く
- Claude Codeとの住み分けが重要: コーディング → Claude Code、知識作業 → Cowork
- 今のところ「これをやりたい」という具体的なユースケースが思い浮かばない状態

## 追記: Cowork vs Claude Code の住み分け整理（2026-04-05）

### Coworkにしかできない・得意なこと

| 機能 | Cowork | Claude Code |
|------|--------|-------------|
| スケジュール実行 | ネイティブ対応（/schedule） | スキル経由で可 |
| Computer Use（GUI操作） | 対応 | 不可 |
| Excel/PPT直接編集 | 対応 | 不可 |
| ターミナル操作 | 不可 | 得意 |
| コード生成・デバッグ | 不向き | 得意 |

### Computer Use について

- スクリーンショットでGUIを認識し、クリック・入力・アプリ起動が可能
- MCPのないアプリ（ブラウザ、Officeアプリ等）が主な対象
- まだ研究プレビュー段階で精度は低め、複雑な操作はミスが出やすい

### Unity操作について

- Coworkで理論上は可能だが、精度・速度の問題で実用的ではない
- Unity操作にはunity-mcp + Claude Codeが圧倒的に優れている（Editor APIを直接叩くため）
- unity-mcpはスクリーンショット取得・Play Mode制御・コンソールログ読み取りに対応済み

### 活用事例（ネット上）

- Excelの財務データ → PowerPointのプレゼン資料を自動生成
- 銀行明細とインボイスを照合して整理したExcelを出力
- SNS（X・Reddit等）の投稿をリサーチしてExcelにまとめる
- ExcelとPowerPoint間のコンテキスト共有（2026年3月追加機能）

### 結論

Coworkはバックオフィス系（財務・マーケ・法務・営業資料）に活路がある。
ゲーム開発との直接的な接点は薄く、現状は「使い所がない」という感覚は妥当。
強いて言えばパラメータ表→仕様書変換、プレイデータ集計レポート自動生成くらい。
