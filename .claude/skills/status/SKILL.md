# status: ナレッジベース状態確認

## やること

1. `entries/` 内の全Markdownファイルのフロントマターを読む
2. 以下のサマリーを表示:

```
ナレッジベース状態
━━━━━━━━━━━━━━━━━━━
未読:     X件（うち S/Aランク: Y件）
読了:     X件
実践済み:  X件
レビュー済: X件
アーカイブ: X件

要対応（S/Aランクで未実践）:
  - [日付] タイトル（ランクS）
  - [日付] タイトル（ランクA）

最終更新: YYYY-MM-DD
```

3. 未読のS/Aランクがある場合、「`/try` で試してみますか？」を提案
