# status: ナレッジベース状態確認

## やること

1. `entries/` 内の全Markdownファイルのフロントマターを読む
2. 以下のサマリーを表示:

```
ナレッジベース状態
━━━━━━━━━━━━━━━━━━━
未読:      X件（うち S/Aランク: Y件）
読了:      X件
実践待ち:   X件（うち S/Aランク: Y件）
実践済み:   X件
アーカイブ: X件

要対応（S/Aランクで未読・実践待ち）:
  - [日付] タイトル（ランクS）[未読]
  - [日付] タイトル（ランクA）[実践待ち]

最終更新: YYYY-MM-DD
```

ステータスの対応:
- `unread`  → 未読
- `read`    → 読了（完了、これ以上やることなし）
- `pending` → 実践待ち（read後、実践したいと判断したもの）
- `tried`   → 実践済み
- `archived`→ アーカイブ

3. 未読またはpendingのS/Aランクがある場合、「`/try` で試してみますか？」を提案
