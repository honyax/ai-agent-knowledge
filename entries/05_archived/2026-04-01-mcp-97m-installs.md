# MCP が9700万インストール到達・エージェントAIの基盤インフラへ

## 3行要約

- MCP（Model Context Protocol）が2026年3月25日時点で9700万インストールを達成し、2024年11月リリース比で4750%成長
- MCPエコシステムは5,800以上のサーバーに拡大し、Linux Foundation傘下の AAIF（Agentic AI Foundation）に寄贈済み
- 「実験的プロトコル」から「エージェントAIの基盤レイヤー」への移行が完了しつつあると業界が評価

## 自分への関連度: B

Blender MCP や Unity MCP を使っている立場として、MCPの普及状況は知識として重要。直接何かを試すというよりは現状把握として有用。

## 詳細

### 成長の背景

- OpenAI、Google DeepMind、Microsoft も MCP の採用を開始
- IDE（Cursor, VS Code等）・クラウドサービス・エンタープライズツールへの組み込みが急増
- AAIF への寄贈により、特定ベンダーへの依存を嫌う企業でも採用しやすくなった

### 批判的な見方も

「MCP is Dead; Long Live MCP!」という記事では、現状の MCP の課題（認証の複雑さ、バージョン管理、セキュリティ）を指摘。急成長の一方で実用上の問題も顕在化している。

### 2026年3月のAnthropicまとめ

TechCrunch と The New Stack が2026年3月のAnthropicを総括。14以上のリリース（Auto Mode、Channels、Scheduled Tasks等）と5回のサービス障害という激動の月だったと評価。

## 試すなら

1. AAIF のサイトで公式 MCP 仕様の最新版を確認する
2. 使用中の Blender MCP サーバーのバージョンを確認し、最新仕様対応状況を調べる
