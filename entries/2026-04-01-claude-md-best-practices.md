# CLAUDE.mdを育てる技術 — ベストプラクティス15選

## 3行要約

- 3ヶ月の運用で導き出した CLAUDE.md のベストプラクティス15選を解説した Qiita 記事が公開された
- 週次レビューサイクルで CLAUDE.md を継続的に改善することで、出力精度が2〜3倍向上するという報告
- 「禁止事項より推奨事項を多く書く」「コンテキストを具体的に書く」など実践的なノウハウが含まれる

## 自分への関連度: S

Claude Code の設定・運用ノウハウは関心領域2の中核。現在の CLAUDE.md の品質向上に直接活かせる内容。

## 詳細

### 主なベストプラクティス（記事より）

- **禁止より推奨**: 「〇〇するな」より「〇〇すること」で書くと指示の曖昧さが減る
- **週次レビューサイクル**: プロジェクト終了後に「今週 Claude に何度も同じことを言った？」を振り返り CLAUDE.md に追記
- **具体的なコンテキスト記述**: 「大規模プロジェクト」より「ファイル数3000以上、モジュール分割済み」のように具体化
- **ロールとスキルセットの明示**: 自分の技術スタックとレベルを書くと回答の深さが変わる
- **セクション分割**: 「コーディング規約」「コミュニケーション」「禁止事項」を分けると読みやすい

### 2026年3月版 完全ガイド（別記事）

CLAUDE.md の書き方・育て方・やりがちな失敗を網羅した記事も公開。初心者から上級者まで対応。

## 試すなら

1. 記事の15選を読み、自分の CLAUDE.md と照合する
2. 「今週 Claude に何度も言ったこと」を列挙する
3. 禁止事項を推奨事項に言い換えて書き直す
4. コンテキスト記述を具体的な数値・事実に置き換える
5. 週次レビューをカレンダーに登録する
