# COYOTE VFX、ゲームエフェクト用テクスチャライブラリを無料配布（Substance 3D Designer元データ付き）

## 3行要約

- C&R Creative StudiosのCOYOTE VFXチームが、ゲームエフェクト制作用テクスチャ集をBOOTHで無料配布（商用利用可）。
- 単なるPNG配布ではなく Substance 3D Designer 用の元データ(.sbs)、独自カスタムノード（"Fit VFX Tex" など端ピクセル保持拡大フィルタ）も同梱。
- Substance 3D Designer 15.0.1以上が必要、利用時はツール記載が推奨される（必須ではない）。

## 自分への関連度: C

ゲーム開発周辺ではあるが、AIエージェント・Claude連携とは直接の関連がない一般的なアセット配布情報。Unity側で自作ゲームのVFX制作をするときに思い出せれば十分。AIの観点では、Substance Designerのカスタムノード設計を「LLMにエフェクト生成パイプラインを書かせるときの参照例」として頭の片隅に。

## 詳細

- 配布元: C&R Creative Studios / COYOTE VFX チーム
- 配布場所: BOOTH（リンクは記事から）
- 公開日: 2026/05/27
- 含まれるもの:
  - ゲームエフェクト汎用テクスチャ
  - Substance 3D Designer 元データ(.sbs)
  - カスタムノード（例: "Fit VFX Tex" - テクスチャの端ピクセルを保持しつつ拡大）
- 利用条件:
  - 商用プロジェクト利用可
  - Substance 3D Designer 15.0.1以上
  - ツール記載（クレジット）推奨

## 試すなら

1. BOOTHで配布物を確認、ライセンス条項を一読。
2. Substance 3D Designerのバージョン要件を満たすか確認。
3. 自作Unityプロジェクトでテクスチャ単体を試用、カスタムノードはあれば触る程度。
4. AI連携の発想として、Substance Graph生成をLLMに書かせる実験のサンプルデータとして保管。
