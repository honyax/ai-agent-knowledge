# Claude Code が速すぎるので「現在地」を可視化したら実装体験が変わった

## 3行要約

- Claude Codeのコード生成速度が速すぎて「今どこを実装しているか」が追えなくなる問題に対し、シーケンス図と色分けで現在地を可視化する手法を紹介
- 実装状態をリアルタイムに把握できるようにすることで、長時間セッションでのコンテキスト把握が改善する
- 大規模実装時の「Claude Codeに何をさせているのか迷子になる」問題への実践的アプローチ

## 自分への関連度: B

ゲーム開発でClaude Codeを使った大規模実装（TPSゲームのAI改造など）を行う際に、実装の現在地を把握しやすくする手法として有用。即実践というよりは「長い実装セッション時の参考手法」として知識として持っておきたい。

## 詳細

手法の概要：
- 実装計画をシーケンス図（mermaid等）で事前に作成
- 各ステップを色分けして「完了/進行中/未着手」を視覚化
- Claude Codeに状態更新を指示して図をリアルタイム更新させる

長時間セッションの問題：Claude Codeは高速でコードを生成するが、人間側が追いつけずに「今何をしているのか」が不明瞭になる。CLAUDE.mdに実装進捗管理のルールを組み込む応用も可能。

## 試すなら

1. 次の大きな実装タスクでmermaidのシーケンス図を事前に作成
2. `CLAUDE.md` に「実装前に現在のステップをシーケンス図で更新してから作業開始」を追加
3. Claude Codeセッション中に定期的に `current_step.md` を更新させる指示を入れる
