# Claude Code ステータスライン完全ガイド2026 — 基礎から自作ツール開発まで

## 3行要約

- Claude Code のステータスラインのカスタマイズ方法を基礎から自作ツール開発まで体系的に解説した記事（2026年4月）
- トークン消費量・モデル名・コスト・Git情報など様々な情報をステータスラインに表示する設定例を紹介
- 独自のステータスライン拡張を作る手順まで踏み込み、運用レベルのカスタマイズが可能に

## 自分への関連度: A

ステータスラインはClaude Codeを日常的に使う中でリアルタイムに状態を確認できる重要な機能。カスタマイズすることでトークン消費・コスト・モデル情報を一目で把握でき、ワークフロー改善に直結する。

## 詳細

ステータスラインはClaude Codeのフッターに表示される情報バー。設定可能な表示項目：

- トークン使用量・残量
- モデル名（Sonnet/Opus/Haiku）
- セッションコスト
- Gitブランチ名・コミット状態
- カスタムシェルスクリプトの出力（任意の情報を追加可能）

自作ツール開発では、`statusline` 設定キーにスクリプトのパスを指定することで独自情報を組み込める。

## 試すなら

1. `settings.json` の `statusline` セクションを確認する
2. 表示したい情報（cost, tokens, model等）をフィールドに追加
3. カスタムスクリプトを `~/.claude/statusline-scripts/` に配置して参照
4. Claude Code を再起動してステータスラインが更新されることを確認
5. 必要に応じてシェルスクリプトで外部情報（Git状態など）を動的に表示
