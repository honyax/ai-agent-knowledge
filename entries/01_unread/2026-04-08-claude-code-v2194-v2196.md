# Claude Code v2.1.94 / v2.1.96 アップデート

## 3行要約

- **デフォルトのeffortレベルがmedium→highに変更**（v2.1.94）。トークン消費量・コストが増加するため要注意
- Amazon Bedrock サポートが Mantle 経由に刷新。インタラクティブな Bedrock セットアップウィザード付き
- エージェントのレート制限によるハングアップ修正、macOS キーチェーン修正など安定性向上

## 自分への関連度: A

effortデフォルト変更はコストに直接影響するため即確認が必要。BedockユーザーはMantle移行も要対応。Claude Code Channelsのコンパクト化など日常使いの改善も含まれる。

## 詳細

### v2.1.94 主な変更

- **デフォルトeffortレベル: `medium` → `high` に変更**
  - 全タスクの思考深度・トークン使用量が増加するため、コスト管理を意識している場合は `/cost` で確認を
- **Amazon Bedrock support via Mantle**: AWS 認証の新パス。既存 Bedrock ユーザーは移行が必要な可能性あり
- **Compact Slack message headers**: Claude Code Channels 経由の Slack 通知が整理された
- **Plugin skill invocation improvements**: プラグインからのスキル呼び出し信頼性向上
- **Fixed agent rate-limit hang**: レート制限でエージェントが無限ハングする問題を修正
- **macOS keychain fix**: macOS でのキーチェーン連携の不具合修正

### v2.1.96 主な変更

- **Fixed Bedrock authorization header issue**: Mantle 移行に伴う Bedrock 認証ヘッダーの問題を修正

## 試すなら

1. `claude --version` で現在バージョンを確認、古ければ `npm update -g @anthropic-ai/claude-code` で更新
2. `/cost` コマンドで最近のトークン使用量を確認し、effort=high 変更の影響を把握
3. Bedrock 利用者は `claude /setup-bedrock` ウィザードで新しい Mantle 認証を設定
4. Slack 連携している場合は通知フォーマットの変化を確認
