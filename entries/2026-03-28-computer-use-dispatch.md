# Claude.ai: Computer Use がPro/Maxプランで利用可能に

## 3行要約

- Claude.aiでComputer Use（画面操作）がPro/Maxプラン向けに提供開始。セットアップ不要でファイル操作・開発ツール操作・画面ナビゲーションが可能
- Dispatch（バックグラウンドタスク実行機能）と組み合わせることで、離席中にPC操作を代行可能
- ポイント＆クリック、テキスト入力、スクロール等の基本的なUI操作をAIが自律的に実行

## 自分への関連度: B

直接的なゲーム開発での利用場面は限定的だが、反復的なGUI操作（Unity EditorやBlenderでの定型作業）の自動化に将来的に使える可能性がある。Dispatchとの組み合わせは、長時間かかるビルド＋テストフローの自動化に有望。

## 試すなら

1. Claude.ai Pro/MaxプランでComputer Useを有効化
2. 簡単なファイル操作タスクで精度を確認
3. Dispatchと組み合わせた自動化シナリオを検討
