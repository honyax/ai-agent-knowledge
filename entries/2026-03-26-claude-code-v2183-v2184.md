# Claude Code v2.1.83–v2.1.84 — managed-settings.d/、PowerShell対応、新Hookイベント

## 3行要約

- **v2.1.84（3/26）**: Windows向けPowerShellツール（opt-inプレビュー）、MCP説明文の2KB上限でコンテキスト肥大化防止、MCP serverの重複排除（ローカル設定優先）、グローバルシステムプロンプトキャッシュがToolSearch有効時も動作
- **v2.1.83（3/25）**: `managed-settings.d/`ドロップインディレクトリで設定フラグメントをアルファベット順にマージ可能、`CwdChanged`/`FileChanged`フックイベント追加（direnv等のリアクティブ環境管理に対応）、トランスクリプト検索（`/`で検索、`n`/`N`でナビゲート）
- セキュリティ面: `CLAUDE_CODE_SUBPROCESS_ENV_SCRUB=1`でサブプロセスからクレデンシャルを除去、`sandbox.failIfUnavailable`でサンドボックス必須化が可能に

## 自分への関連度: S

Windows環境でClaude Codeを使用しているため、PowerShellツールは直接的に影響。CwdChanged/FileChangedフックはプロジェクト切り替え時の自動設定に活用可能。managed-settings.d/はチーム設定管理の改善に使える。

## 詳細

### v2.1.84の注目機能
- **PowerShellツール**: Windows向けopt-inプレビュー。BashツールがLinux/macOS前提だった問題を解決
- **環境変数オーバーライド**: `ANTHROPIC_DEFAULT_{OPUS,SONNET,HAIKU}_MODEL_SUPPORTS`でモデル能力をカスタム指定可能
- **アイドルリターンプロンプト**: 75分以上アイドルのセッションに`/clear`を促すプロンプト表示
- **TaskCreatedフック**: タスク作成時に発火する新フックイベント
- **MCP説明文2KB制限**: コンテキスト肥大化を防止
- **VS Code**: レートリミット警告バナー（使用率とリセット時間を表示）

### v2.1.83の注目機能
- **managed-settings.d/**: ポリシーフラグメントを個別ファイルで管理、アルファベット順にマージ
- **CwdChanged/FileChangedフック**: ディレクトリ変更やファイル変更に反応するフックイベント
- **トランスクリプト検索**: `Ctrl+O`でトランスクリプトモード→`/`で検索
- **Agent initialPrompt**: エージェント定義にinitialPromptフロントマターで自動送信の初回プロンプトを設定
- **セキュリティ**: `CLAUDE_CODE_SUBPROCESS_ENV_SCRUB=1`でサブプロセスの認証情報を除去

### 主要なバグ修正
- Voice push-to-talkの文字リーク修正
- 大きなファイルのdiffハング修正（5秒タイムアウト）
- MCP設定取得の起動時3秒遅延の修正
- Windowsパス安全性の改善（C:\, C:\Windows等の危険な削除を検出）

## 試すなら

1. `claude --version`でv2.1.84に更新されているか確認
2. PowerShellツールを試す: Windowsプロジェクトでopt-in設定を有効化
3. `CwdChanged`フックを設定して、プロジェクト切り替え時に環境変数を自動設定
4. トランスクリプト検索: `Ctrl+O`→`/`→検索語句で過去の会話を検索
5. `CLAUDE_CODE_SUBPROCESS_ENV_SCRUB=1`を環境変数に設定してセキュリティ強化
