# Claude Codeによる日常業務の自動化 — コーディング以外への応用

## 3行要約

- Claude Codeをコーディング以外の業務（経費精算、メールリマインド、スライド作成、タスク管理）に応用する実践ガイド
- 「プチ仕様駆動開発」フレームワーク: PLAN・SPEC・TODO・KNOWLEDGEの4ドキュメントでAI協働を体系化
- Opus 4.6では十分な情報をインプットすれば品質とスピードを両立可能。ナレッジ蓄積・再利用が組織の生産性格差の決定要因

## 自分への関連度: A

コーディング以外でのClaude Code活用という視点が新鮮。経費精算やスライド作成の自動化は直接参考になる。PLAN/SPEC/TODO/KNOWLEDGEの4ドキュメント体系は、このナレッジベース自体のワークフロー改善にも応用できそう。

## 詳細

### 実践例
- **経費精算**: MoneyForward + Gmail連携で30分→5分に短縮
- **メールリマインド**: EventBridge + Bedrock Agent Coreのサーバーレス構成
- **スライド作成**: Markdown（Marp）ベースでテンプレート化
- **タスク管理**: Todoist MCPサーバー統合

### 哲学
- 「自動化ツール」ではなく「優秀な同僚に仕事を任せる感覚」
- 完全自動化より「半自動化」で十分という現実的アプローチ

## 試すなら

1. 記事のPLAN/SPEC/TODO/KNOWLEDGEフレームワークを自分のプロジェクトに適用
2. Marp（Markdownスライド）でプレゼン資料作成をClaude Codeに任せてみる
3. Todoist MCP等のMCPサーバーでタスク管理連携を試す
