# Claude Code v2.1.172〜v2.1.178: ネスト/サブエージェント、パラメータ指定permission、ネストskillサポート

## 3行要約

- v2.1.172: サブエージェントが自前のサブエージェントを最大5階層までspawnできるネストsub-agent対応。permission rule のワイルドカードドメイン（`WebFetch(domain:*.example.com)`）がサブドメインを正しく許可/拒否/確認できるよう修正。
- v2.1.178: permission rule に `Tool(param:value)` 構文（例: `Agent(model:opus)` でOpusサブエージェントをブロック）が追加。ネストした `.claude/skills/` のskillが、その配下のファイルを編集中のときだけロードされる仕組みに。
- v2.1.173: Fable 5モデル名の `[1m]` サフィックスが正規化されないバグ修正、Windowsの "sandbox dependencies missing" 誤警告を抑制。

## 自分への関連度: S

permissionの細かい制御は [[user_hooks_usage]] の課題（hooksをほぼ使ってない、CLAUDE.mdのシェルツール優先順位ルールで許可リスト前提）に直結する。`Agent(model:*)` で特定モデルを排除できると、コスト最適化や暴走防止に効く。ネストskillサポートは自分のskill構成（[[project_custom_skills]]）にも影響するため、要動作確認。

## 詳細

### v2.1.172 主要変更
- **ネスト sub-agent**: subagent から subagent を呼べる（最大5階層）。Dynamic Workflowsの「サブエージェントがparallelでさらに分岐」が安定運用に。
- **permission ワイルドカード修正**: `WebFetch(domain:*.example.com)` のような複数階層サブドメインのマッチが正しく動くように（以前はマッチしないバグ）。

### v2.1.173
- **Fable 5モデル名正規化**: 内部的に付与される `[1m]` (1Mコンテキスト指定) サフィックスがUI/状態管理で剥がされなかったバグを修正。
- **Windows sandbox警告**: 誤検知だった `sandbox dependencies missing` の起動時警告を削除。

### v2.1.178 (最新) 主要変更
- **Tool(param:value) permission構文**: 例 `Agent(model:opus)`, `Bash(command:rm)`, ワイルドカード `*` も使える。tool inputに対する細粒度制御が可能に。
- **ネスト `.claude/skills/` サポート**: トップレベル `.claude/` だけでなく、サブディレクトリ配下の `.claude/skills/` も、そのスコープのファイル編集時にロード。同名skill衝突時は `<dir>:<name>` で両方使える。
- **その他**: `/doctor`, Remote Control, `/bug` の改善。crashes、auth、websocket、subagent reliability、compaction fallback、Vim undo、statusline links、VS Code IME動作の修正。

### v2.1.171は欠番
npmへの公開がスキップされ、v2.1.170 → v2.1.172 へ直接更新された。

## 試すなら

1. `claude --version` で現状確認、最新（v2.1.178以降）に更新。
2. `.claude/settings.json` の permissions に `Agent(model:opus)` を試験追加し、サブエージェント呼び出し時にブロックされるか確認（コスト管理用途）。
3. プロジェクトのサブディレクトリ（例: `frontend/`）配下に `frontend/.claude/skills/test-skill/` を作って、フロント側ファイル編集時のみロードされるか確認。
4. WebFetch を使う既存skillで、`WebFetch(domain:*.anthropic.com)` 設定が正しくサブドメインに効くか検証。
5. ネスト sub-agent: 自作Skillで `/code-review` 等から `Agent` ツールを呼ぶ場合、子エージェントがさらに孫を呼ぶケースが安定するか確認。
