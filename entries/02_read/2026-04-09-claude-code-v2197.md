# Claude Code v2.1.97 アップデート

## 3行要約

- **Focus view トグル（Ctrl+O）追加**: NO_FLICKERモードでプロンプト・ツール要約・最終レスポンスのみ表示するビューが使えるように
- **`refreshInterval` status line 設定追加**: ステータスラインのコマンドを N 秒ごとに自動再実行できるようになった
- NO_FLICKERモードの日本語/韓国語テキスト文字化け修正、Write ツールのdiff計算が大ファイルで60%高速化

## 自分への関連度: S

日本語でClaude Codeを使用している場合にNO_FLICKERモードの文字化けが解消される。`refreshInterval`はステータスラインのカスタマイズに直接使える新機能。Focus viewはタスクに集中したいときの実用機能。

## 詳細

### 主な新機能

- **Focus view toggle (Ctrl+O)**: NO_FLICKERモードでプロンプト・1行ツール要約（edit diffstat付き）・最終レスポンスのみ表示。ノイズを減らした集中モード
- **`refreshInterval` status line 設定**: ステータスラインのシェルコマンドをN秒ごとに再実行。ステータスラインにリアルタイム情報を表示する用途に使える
- **`workspace.git_worktree` を status line JSON 入力に追加**: Worktree 情報をステータスラインで参照可能に
- **`/agents` に `● N running` 表示追加**: 実行中のサブエージェント数がリアルタイムで確認できる

### 主な修正

- **NO_FLICKERモード**: 日本語・韓国語テキストの文字化け修正（Windows）
- **MCP接続**: プラグインMCPサーバーがセッション開始時に「connecting」で固まる問題を修正
- **サブエージェントのWorktree分離**: 安定性向上
- **Write ツール**: 大ファイルでのdiff計算を60%高速化
- **Bashツール権限、OAuth認証、レート制限ハンドリング**など多数の細かい修正

## 試すなら

1. `claude --version` で現在バージョンを確認
2. 古ければ `npm update -g @anthropic-ai/claude-code` で v2.1.97 へ更新
3. NO_FLICKERモードで日本語テキストが正しく表示されることを確認
4. `refreshInterval: 30` などをsettings.jsonのステータスライン設定に追加してみる
5. Ctrl+O で Focus view のオン/オフを試す
