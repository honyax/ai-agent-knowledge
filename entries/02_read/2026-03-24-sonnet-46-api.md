# Claude Sonnet 4.6リリース & API主要変更まとめ

## 3行要約

- Sonnet 4.6がリリース（2/17）。コーディング・エージェント・専門業務でフロンティア性能。1Mトークンコンテキストウィンドウ（ベータ）対応
- Web SearchとTool Callingが正式GA（betaヘッダー不要に）。コード実行ツールがweb search/fetch併用時に無料化
- Structured Outputsが正式GA。`output_format` → `output_config.format` に移動。Data Residency制御（`inference_geo`パラメータ）追加

## 自分への関連度: A

カードゲームのAI対戦相手やゲーム内アシスタントにClaude APIを使う場合、Sonnet 4.6はコスト効率が良い選択肢。Structured Outputsの正式GAでゲームデータ（カードリスト、デッキ構成等）の構造化出力が安定する。Web SearchのGA化も、ゲーム内リサーチ機能やメタゲーム分析に活用可能。

## 試すなら

1. APIでSonnet 4.6（`claude-sonnet-4-6`）にリクエストを送って応答品質を確認
2. Structured Outputsを `output_config.format` で試す（JSON Schema指定）
3. Web Search toolを betaヘッダーなしで呼び出せることを確認

## 感想・考察

**良かった点**: Structured Outputs GAと `output_config.format` への統一は歓迎。ゲームデータ（カードリスト、デッキ構成）の構造化が安定するのは直接使える。

**微妙な点**: `output_format` → `output_config.format` の移行が必要で既存コードへの影響確認が必要。実際の品質はコーディングタスクで試すまで不明。

**ワークフローへの適用**: ゲーム内AI対戦相手のモデルIDを `claude-sonnet-4-6` に更新。Web Search GAでゲーム内メタ情報取得も簡単になる。このリポジトリのClaude Code自体も `claude-sonnet-4-6` を継続使用中（2026-03-30確認）。
