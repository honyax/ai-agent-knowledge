# Claude Code v2.1.180〜v2.1.193: auto モード destructive-block、`claude mcp login`、`/rewind` 拡張、MessageDisplay フック

## 3行要約

- **v2.1.183**: auto モードで destructive な git コマンド（`reset --hard` / `checkout -- .` / `clean -fd` / `stash drop` / 自分以外のコミットへの `commit --amend`）を明示要求なしにブロック。`terraform destroy` / `pulumi destroy` / `cdk destroy` も特定スタック指定がない限りブロック。非推奨モデル指定時の警告も追加。
- **v2.1.185〜v2.1.193**: `claude mcp login` でシェルから MCP サーバー認証可能に（インタラクティブ `/mcp` 不要、`claude mcp logout` で削除）。`/rewind` が `/clear` 前まで遡れるように。background subagent の permission prompt がメインセッションに表示されるようになり auto-deny されない。シェルモードが `! npm test` のコマンド出力に再プロンプトなしで応答。
- **フック関連**: `SessionStart` フックが `reloadSkills: true` でスキル再スキャン可能・`hookSpecificOutput.sessionTitle` で起動時にセッションタイトル設定可能に。新規 `MessageDisplay` フックでアシスタントメッセージ表示時にテキスト変換/非表示が可能。`PostToolUse` の `updatedToolOutput` が全ツールで動作（旧 MCP 限定）。`/skills` にタイプフィルタ検索ボックス追加。

## 詳細

### v2.1.183: Auto-Mode Safety Guardrails

破壊的操作をブロックする具体リスト:

- **Git destructive**: `git reset --hard`, `git checkout -- .`, `git clean -fd`, `git stash drop` を「ユーザーが明示要求していない」とみなしてブロック。
- **Commit amend 保護**: そのセッションでエージェントが作っていないコミットに対する `commit --amend` をブロック（公開済みコミットへの破壊的改変防止）。
- **IaC destructive**: `terraform destroy` / `pulumi destroy` / `cdk destroy` は明示スタック指定なしでブロック。
- **モデル非推奨警告**: 指定したモデルが deprecated または auto-update された場合に警告。

CLAUDE.md の「Executing actions with care」セクションを harness 側でも強制するアップグレードに位置づく。

### v2.1.185 - v2.1.193 (週次サマリ: 6/22-26)

- **`claude mcp login` / `claude mcp logout`**: 設定済み MCP サーバーをシェルから直接認証。CI / Routines / cron で初期認証を済ませておける。
- **`/rewind`**: `/clear` 後でも `/clear` 直前まで遡って会話再開可能に。
- **shell mode 改良**: `! npm test` のような ! プレフィックスコマンドの出力に対し、再プロンプトなしで Claude が解説を返す。
- **background subagent の permission**: 従来 auto-deny になっていた permission prompt が、メインセッション側に上がるように。

### v2.1.185 細部

- **stream-stall hint**: 「Waiting for API response · will retry in …」に変更（旧: 「No response from API · Retrying in …」）。トリガーが 10s → 20s に延長。
- **MCP OAuth scope 修正**: scope 未指定時に authorization server の `scopes_supported` 全カタログ要求していたバグを修正（GitLab self-hosted などで `invalid_scope` 失敗していた）。
- **MCP headersHelper auth**: ツール呼び出しが 401/403 を返したとき helper を再実行・再接続する自動リトライ。

### フック/Skill 関連 (v2.1.180 周辺)

- **`SessionStart` 強化**: `reloadSkills: true` で hook が同セッション中にインストールしたスキルを即時利用可能に。`hookSpecificOutput.sessionTitle` で起動時のセッションタイトル設定。
- **新フック `MessageDisplay`**: アシスタントメッセージのテキストを表示時に変換/非表示にできる。検閲/翻訳/プライバシーマスクなどの用途。
- **`PostToolUse` 改良**: `hookSpecificOutput.updatedToolOutput` が全ツール対応（旧: MCP のみ）。任意ツールの出力差し替えが可能に（RTK 的な圧縮を自前 hook で書ける）。
- **hook matcher 修正**: カンマ区切り matcher（`"Bash,PowerShell"`）が silently 発火しないバグ修正。ハイフン付き識別子（`code-reviewer`, `mcp__brave-search`）の substring マッチを exact マッチに修正（[[2026-06-17-claude-code-v21171-v21178]] でも同種修正あり、追加修正）。
- **`/skills` 検索**: タイプフィルタの検索ボックス追加、長いリストでもスクロール不要に。

### その他

- **fullscreen mouse**: `CLAUDE_CODE_DISABLE_MOUSE_CLICKS` で fullscreen モードのマウスクリック/ドラッグ/ホバーを無効化（ホイールスクロールは維持）。
- **voice dictation**: macOS で長時間セッション中にデフォルト入力デバイスが変わったとき silence が記録されるバグ修正、スペース無し言語（日本語/中国語など）で auto-submit が発火しないバグ修正。
- **CPU 使用率**: v2.1.191 でストリーミング中のテキスト更新を 100ms 間隔に集約し ~37% CPU 削減。

## 感想・考察

### `claude mcp login` の意味と限界（2026-07-03）

「手作業で `/mcp` を実行しなくても MCP サーバー認証できるようになったのか」という問いから整理。

**変わったこと**: 認証の**起動元**が「インタラクティブ Claude Code セッション内の `/mcp` メニュー」から「シェルコマンド」に置き換わった。

- 旧: `claude` 起動 → `/mcp` 実行 → メニュー選択 → OAuth 承認
- 新: `claude mcp login <server>` をシェルから直接。`claude mcp logout <server>` でトークン削除。

**変わっていないこと**: OAuth の承認ステップ自体（ブラウザで Approve を押す部分）は残る。完全ゼロ手動にはなっていない。

**嬉しい点**:

- セッション起動不要
- スクリプト化可能（CI / GitHub Actions / cron / Routines の初期化ステップに組み込める）
- 複数 MCP サーバーの事前一括認証が可能

**まだ足りない点**: 初回 Connect のブラウザ手動承認は残る。会社での UE5.8 業務（[[user_company_ue58]]）で MCP サーバー（UE 用 MCP、社内ツール MCP など）を初期セットアップする際、この手動 Connect が地味に手間。「もはや無くても良いのに」と思うが、まだ必要そう。

**次を追う手がかり**: v2.1.195 前後で「ブラウザ不要の MCP 認証」が入ったという未確認情報あり。device flow や PAT (Personal Access Token) 経由の認証パスと推測。会社環境で完全自動化に近づけたい場合はここを追う価値がある（要検証）。
