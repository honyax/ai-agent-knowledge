# Claude Code v2.1.110: TUIフルスクリーン・モバイルプッシュ通知・/focusコマンド

## 3行要約

- `/tui fullscreen` コマンドでフリッカーなしのフルスクリーンモードに即時切り替え可能になった
- Remote Control + 設定有効時にClaudeがモバイルへプッシュ通知を送れるツールが追加された
- `Ctrl+O` はverboseトランスクリプトのトグルに変更され、フォーカスビューは新設の `/focus` コマンドへ分離

## 自分への関連度: S

TUIフルスクリーンはv2.1.84で追加された/fullscreenの後継改善。リモート実行中にスマホへ通知が届く仕組みは長時間タスクの監視ワークフローに直結する。

## 詳細

**TUIフルスクリーンモード**
- `/tui fullscreen` で同一会話内のままフルスクリーンに切り替え
- `autoScrollEnabled` 設定でフルスクリーン中の自動スクロールを無効化可能
- macOS Terminal.app等でのgarbled startup renderingを修正

**プッシュ通知ツール**
- Remote Controlが有効かつ設定で「Push when Claude decides」を有効にした場合、Claudeが判断してモバイルへ通知を送信

**UX変更**
- `Ctrl+O`: verbose transcript トグル専用に変更
- `/focus`: フォーカスビューのトグルを独立コマンド化
- `/plugin` インストール済みタブ改善: 要対応・お気に入りが上位表示、無効アイテムは折りたたみ、`f` でお気に入り登録

## 試すなら

1. Claude Code を最新版に更新 (`npm update -g @anthropic-ai/claude-code`)
2. セッション中に `/tui fullscreen` を実行してフルスクリーンを確認
3. モバイルアプリでRemote Controlをセットアップしプッシュ通知を有効化
4. 長時間タスクを投げて通知が届くか確認

## 感想・考察

プッシュ通知を実際に試みたが、独立したターミナルで `/config` でPush通知を有効化し `claude --remote-control` を起動しても、スマホへの通知は届かなかった。公式ドキュメントによると通知はClaudeが「必要と判断したとき」にしか送らない設計で、単に起動・設定しただけでは届かない。長時間タスクの完了時や判断待ちになったときに初めて送信される模様。実際に長いタスクを流した状態でRemote Controlを接続してから再検証する必要がある。
