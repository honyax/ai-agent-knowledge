# Claude Code v2.1.121〜v2.1.123 — alwaysLoad MCP・/skills 検索・PR URL resume

## 3行要約

- v2.1.121（2026-04-28）: MCP server config に `alwaysLoad` オプション追加でツール検索遅延をスキップ可能。`/skills` に絞り込み検索ボックス追加。PostToolUse Hook が全ツールの出力を置換可能に（従来は MCP のみ）
- v2.1.122（2026-04-29）: `/resume` が PR URL を受け付ける（GitHub/GitLab/Bitbucket 対応）。PR URL を貼ると、その PR を作ったセッションを検索して再開できる
- v2.1.123（2026-04-29）: OAuth 認証の 401 リトライループ修正（`CLAUDE_CODE_DISABLE_EXPERIMENTAL_BETAS=1` 環境下）。退行バグ多発期だった v2.1.119/120 から3版で安定化方向

## 自分への関連度: A

`alwaysLoad` は MCP ツールが多くて Tool Search の遅延が気になるケースで即効果。`/skills` 検索ボックスは、自分のナレッジベース運用でカスタム Skill が増えてきた時に役立つ。PR URL → resume はコードレビュー時の文脈復元に直結する強力な機能。Bedrock/Vertex の structured output 修正は API 利用者向けで自分には非該当。

## 詳細

### v2.1.121 の主な追加・修正

**新機能**
- `alwaysLoad: true` を MCP server config に指定すると、その server のツール群が **Tool Search 遅延をスキップ**して常時利用可能に
- `claude plugin prune` で孤立した auto-installed プラグイン依存を削除（`uninstall --prune` でカスケード）
- `/skills` に **type-to-filter 検索ボックス**追加（長いリストで便利）
- PostToolUse Hook が `hookSpecificOutput.updatedToolOutput` で**全ツールの出力を置換**できるように（従来は MCP のみ対応）
- フルスクリーンモード: スクロールアップして読んでいる時にプロンプト入力でスクロールが下に飛ばなくなった
- ターミナル幅オーバーフロー時のダイアログがスクロール可能に（矢印・PgUp/PgDn・home/end・マウスホイール）

**修正**
- claude.ai MCP コネクター: connector list 取得が一時的に認証エラーで失敗した時に黙って消える問題を修正
- リモートセッションでの「Always allow」ルールが worker 再起動で消える問題を修正
- ネイティブビルドの managed-settings.json で `NO_PROXY` が一部 HTTP クライアントで効かない問題を修正

### v2.1.122 の主な追加・修正

**新機能**
- **`/resume` が PR URL を受け付ける**: PR URL を `/resume` 検索ボックスに貼ると、その PR を作ったセッションを検索可能。GitHub/GitHub Enterprise/GitLab（self-hosted 含む）/Bitbucket 対応
- `/mcp` が claude.ai connector の重複表示時にヒント表示

**修正**
- `/branch` が rewound timeline を含むセッションから fork すると `tool_use ids without tool_result blocks` エラーで失敗する問題
- `/model` が Bedrock application inference profile ARN で Effort オプションを表示しない問題
- Vertex AI / Bedrock の structured output が `invalid_request_error: output_config` で失敗する問題

### v2.1.123 の主な修正

- OAuth 認証が `CLAUDE_CODE_DISABLE_EXPERIMENTAL_BETAS=1` 設定時に **401 リトライループ**で失敗する問題を修正
