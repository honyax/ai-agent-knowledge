# Claude Code v2.1.126 — `claude project purge`・OAuthコード貼付ログイン・Mac sleep耐性・managed-settings セキュリティ修正

## 3行要約

- v2.1.126（2026-05-02、32項目）: 新サブコマンド `claude project purge [path]` でプロジェクト単位のClaude Code状態（transcripts・設定）を一括削除可能。`--dry-run/-y/-i/--all` 対応
- `--dangerously-skip-permissions` の保護対象が拡大し、`.claude/`・`.git/`・shell設定ファイルへの書き込みは引き続きプロンプト確認される（誤って消すリスクを軽減）。`/model` ピッカーが `ANTHROPIC_BASE_URL` 経由のゲートウェイの `/v1/models` を読み実モデル一覧を表示
- 重要な安定性修正: (1) OAuthコードをターミナルへ貼り付けてログインできる（WSL2/SSH/コンテナでブラウザコールバックが localhost に届かないケース）、(2) Mac sleep 復帰後の "Stream idle timeout" 解消、(3) Windows での日本語/中韓文字レンダリング修正（no-flicker mode）、(4) `allowManagedDomainsOnly` / `allowManagedReadPathsOnly` が上位 managed-settings に sandbox ブロックがない時に無視される脆弱性修正

## 自分への関連度: S

Windows ネイティブ拡張環境のユーザとして直撃する修正が多数:
- **PowerShell 7 を primary shell として正しく検出**: 自分は PowerShell 環境なので地味に効く
- **Windows 日本語文字化け修正**: no-flicker mode 利用時の日本語表示問題が解消
- **Windows clipboard が EDR/SIEM テレメトリに露出しない修正**＋22KB超のセレクションがクリップボードに乗らないバグの修正
- **`--dangerously-skip-permissions` の保護対象拡大**: 自分はそのフラグを多用しないが、`.claude/` 以下を AI に誤書きされるリスクが下がるのは心理的に大きい
- **Mac sleep セッション維持**: 直接は使わないが、Opus 4.7 の長時間 thinking がローカル idle timeout に誤検知される問題は Windows でも同根の可能性

加えて `claude project purge` は、自分が複数のサブプロジェクトで Claude Code を試している中で、不要な transcripts を整理する手段として即使える。`/model` のゲートウェイ統合は LiteLLM 経由運用者向けで自分には非該当だが、セキュリティ修正（managed-settings sandbox）は組織配布版を使うチームに重要。

## 詳細

### 主要追加機能（v2.1.126）

- **`claude project purge [path]`**: 指定プロジェクトの Claude Code 状態（transcripts・設定など）を全削除する新サブコマンド。`--dry-run`（削除対象のプレビュー）、`-y/--yes`（確認スキップ）、`-i/--interactive`（個別確認）、`--all`（複数プロジェクト一括）に対応
- **`/model` のゲートウェイ統合**: `ANTHROPIC_BASE_URL` が Anthropic 互換ゲートウェイ（LiteLLM 等）を指すとき、ゲートウェイの `/v1/models` を読んで実際に提供されているモデル一覧を表示
- **`claude_code.skill_activated` OpenTelemetry イベント拡張**: ユーザがタイプしたスラッシュコマンドでも発火、新しい `invocation_trigger` 属性を含む
- **Auto mode スピナーの色変化**: 権限チェックがストールしたら赤に変わり、状態が見えるように

### セキュリティ・権限まわり

- **`--dangerously-skip-permissions` の保護範囲拡大**: `.claude/`・`.git/`・shell 設定ファイル（`.bashrc`/`.zshrc`/PowerShell profile 等）への書き込みは、このフラグ下でも引き続きプロンプト確認される
- **`allowManagedDomainsOnly` / `allowManagedReadPathsOnly` 修正**: 上位優先 managed-settings ソースに sandbox ブロックがないと、これらの制限が黙って無視されていた脆弱性を修正。組織配布版を使うチームは展開前に挙動の差分を確認することを推奨
- **Host-managed deployments の自動分析無効化を撤回**: Bedrock/Vertex/Foundry でテレメトリが自動 OFF になる挙動を変更（観測可能性を取り戻す）

### Windows / プラットフォーム関連

- **PowerShell 7 検出改善**: 有効時は PowerShell を primary shell として扱う
- **Windows 日本語/中韓文字レンダリング修正**: no-flicker mode で表示が崩れていた問題
- **Windows クリップボード**: 書き込みが EDR/SIEM テレメトリに露出しない、22KB超のセレクションが正しくクリップボードに到達
- **PowerShell tool**: bare `--` を `--%`（stop-parsing token）と誤認していたバグ修正

### 認証・接続安定性

- **OAuth コードのターミナル貼付ログイン**: WSL2/SSH/コンテナなど、ブラウザコールバックが localhost に届かない環境で `claude auth login` がコード貼付ログインに対応
- **OAuth タイムアウト系の複数修正**: 低速/プロキシ経由・IPv6-only devcontainer・"organization disallows OAuth" のエラー誘導改善
- **OAuth refresh token race 修正**: 並行クレデンシャル書き込みで有効な refresh token がクリアされる競合を解消

### 安定性・UX 修正

- **Mac sleep 後の "Stream idle timeout" 解消**: Opus 4.7 の長時間 thinking pause を idle と誤判定していた問題の修正（バックグラウンド・リモートセッションも対象）
- **空ターン後にアシスタント出力が描画されないハング**を修正
- **Cursor / VS Code 統合ターミナル（v1.92〜v1.104）でのトラックパッドスクロール改善**
- **claude.ai MCP コネクタ**が、手動追加された needs-auth 状態のサーバに抑制されていた問題を修正
- **`Ctrl+L`** が画面再描画のみ（プロンプトをクリアしない）に変更、readline 標準動作に整合
- **Read tool**: ファイルごとのマルウェア評価リマインダ削除（誤拒否を回避）
- **`/plugin` Uninstall** の表示を "Enabled" → "Uninstalled" に修正
- **`/remote-control`** リトライ UI が "connecting" のまま見えていた問題の修正・各リトライ結果を表示
- **Agent SDK ハング修正**: 並列ツール呼び出しでモデルが不正なツール名を出した時のハング
- **Plan mode tools** が `--channels` 起動の対話セッションで使えなかった問題の修正
- **Deferred tools (WebSearch/WebFetch)** が `context: fork` 系 skill の最初のターンでも使えるように

## 試すなら

1. Claude Code を v2.1.126 にアップデート（`claude --version` で確認）
2. `claude project purge --dry-run` を任意プロジェクトで実行し、削除対象のプレビューを確認
3. `/model` を開いて、ゲートウェイ運用者ならモデル一覧の自動取得を確認
4. WSL2/SSH/コンテナ環境を使っているなら、OAuth ログインが切れたタイミングでコード貼付フローを試す
5. Windows ユーザは no-flicker mode で日本語・絵文字・コードブロックの表示が崩れていないか確認
