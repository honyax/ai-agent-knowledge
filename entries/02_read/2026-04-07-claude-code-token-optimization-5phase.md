# Claude Code トークン消費を半減させる5フェーズ運用術

## 3行要約

- CLAUDE.md を200行以下に保つ・タスク切替時に `/clear` を打つ、という2点がコスト削減の最重要施策
- 5つのフェーズ（準備→開始→実行中→タスク切替→振り返り）でコンテキストを意識的にコントロールする
- サブエージェントへの調査委任と `/btw` コマンド（履歴に残さない確認）が実行中の節約に有効

## 自分への関連度: A

日常的に Claude Code を使っている自分には直接コスト削減につながる実践的な知識。CLAUDE.md が既に長くなっている場合に特に有効。

## 詳細

**5フェーズの概要:**

| フェーズ | 内容 | ポイント |
|---------|------|--------|
| Phase 1: セッション準備 | CLAUDE.md を200行以下に保つ | 毎リクエストに含まれるため長すぎるとトークン浪費 |
| Phase 2: タスク開始 | モデル選択・プランモード活用 | Sonnet をデフォルトに、複雑タスク以外は Opus を避ける |
| Phase 3: 実行中 | サブエージェントへの調査委任 | `/btw` コマンドで履歴に残さない確認 |
| Phase 4: タスク切替 | `/clear` でコンテキストリセット | 「最も簡単で最も効果がある」施策 |
| Phase 5: 振り返り | `/cost`・`/stats` でコスト確認 | 効果を測定して習慣化 |

**核心的メッセージ:** 「タスクが変わったら `/clear` を打つ」習慣が最大の節約につながる。

## 試すなら

1. 自分の CLAUDE.md の行数を確認して200行を超えていたらスリム化する
2. 次のセッションからタスク切替時に意識的に `/clear` を実行する
3. `/cost` で現セッションのモデル別コストを確認する習慣をつける
4. サブエージェントに委任できる調査タスクをリストアップする
