# Anthropic、Series H で $65B 調達・評価額 $965B へ — 年換算売上は約 $47B に到達

## 3行要約

- Anthropic が Series H で $65B（650億ドル）を調達し、ポストマネー評価額が $965B（約9650億ドル）に。創業5年で世界最高クラスの評価額のスタートアップに。
- 年換算売上（annualized revenue）は約 $47B（470億ドル）と公表。Claude をコード生成や各種業務・個人タスクに使う個人・組織からの収益が伸びている。
- 発表は Opus 4.8 リリース（[[2026-05-28-claude-opus-48-release]]）と同タイミング。Claude 需要の急増が背景。

## 自分への関連度: B

Anthropic の方針・体力（関心領域8）に関わる事業ニュース。直接ワークフローは変わらないが、過去の収益・資金関連エントリ（[[2026-04-08-anthropic-30b-revenue-google-tpu]]）の続報として、製品継続性や投資余力の判断材料になる。$30B 規模だった売上感が $47B へと加速している点が変化。

## 詳細

- 評価額・売上はいずれも自己申告／報道ベースの数字。年換算売上はランレートであり実績会計年度の売上とは異なる点に注意。
- 資金は計算資源（過去の SpaceX/Colossus や Google TPU 取引 [[2026-05-10-anthropic-spacex-colossus-deal]] / [[2026-04-08-anthropic-30b-revenue-google-tpu]]）への投資に向かう流れと整合。
- 評価額は今年2月の $380B から約2.7倍に急増。IPO 前の最後の大型私募とみられている。

- VC・機関投資家が主体で、そこに**メモリ半導体メーカー（Samsung/SK Hynix/Micron）とクラウド勢（Amazon）が戦略的に参加**する構図。本文の「資金が計算資源に向かう」考察を出資者側からも裏付ける。

### 出資とインフラ確保の関係（Colossus との違い）

Anthropic の compute 確保には「向きの違う」2タイプが併存している。

| 取引 | 性質 | 資本関係 |
|------|------|---------|
| SpaceX/xAI Colossus 1 [[2026-05-10-anthropic-spacex-colossus-deal]] | 容量レンタル（短期の推論キャパ補填）。設備は xAI/SpaceX 保有 | なし（Anthropic→xAI への支出） |
| **AWS（Trainium）** | チップ供給 | **出資あり（今回 $5B）** |
| Samsung/SK Hynix/Micron | メモリ供給見込み | 今回出資参加 |

- Colossus が「短期の容量賃借」なのに対し、Amazon やメモリ各社の出資は**資本でインフラ供給網を囲い込む中長期の動き**。
- 特に Amazon は「出資者」かつ「AWS Trainium の供給者」の二役で、出資した資金の一部が AWS 利用料として還流する**循環的な資本・計算資源の結びつき**になりやすい。投資＝双方向のインフラ確保策と読める。
