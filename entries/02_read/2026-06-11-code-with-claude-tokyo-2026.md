# Code with Claude Tokyo 2026 / Extended Tokyo 開催レポート

## 3行要約

- 2026/06/10 にAnthropic公式の「Code with Claude Tokyo」がFairmont Tokyoで開催、翌6/11には独立開発者・アーリーステージ起業家向け「Code with Claude Extended Tokyo」が併催された。
- セッションテーマはAIエージェント開発のベストプラクティス、組織のAI活用、「コードを書かなかった人がBuilderになる」現象など、SFのCode with Claude 2026（[[2026-05-10-code-with-claude-2026-keynote]]）の延長線。
- 日本コミュニティの参加レポートが多数公開、Anthropic日本展開の本格化を示すマイルストーン。
