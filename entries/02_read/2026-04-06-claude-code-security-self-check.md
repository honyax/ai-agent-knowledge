# Claude Code セキュリティセルフチェック指示文 — axiosのRAT混入事件を踏まえた対策

## 3行要約

- npmの`axios`パッケージへのRAT（Remote Access Trojan）混入事件を受け、Claude Codeにセキュリティセルフチェックをさせるプロンプトを共有した記事
- シークレット漏洩・悪意ある依存関係の混入・不審なコード変更をClaude Code自身に検査させる手法
- Claude Code v2.1.88ソースコード流出インシデントとほぼ同時期（2026年4月初旬）に発生した、OSSサプライチェーン攻撃への実践的な対応策

## 自分への関連度: A

AIコーディングエージェントのセキュリティリスクは関心領域の上位。axiosへのRAT混入はClaude Codeが自動でインストールを提案する可能性のある依存関係で、ゲーム開発でもTypeScriptプロジェクトでよく使われる。セルフチェックのプロンプトは即座に使える実践的な対策。

## 詳細

**背景インシデント（2026年4月初旬）:**
- `axios` npmパッケージにRAT（遠隔操作マルウェア）が混入
- Claude Codeが自動でOSSパッケージを採用・インストールするワークフローでリスクが顕在化
- これはClaude Code v2.1.88のソースコード流出インシデントと同時期に発生

**セルフチェックの内容（推定）:**
- インストール済みパッケージの整合性確認
- `.env`等の機密ファイルへのアクセス履歴を疑う
- 不審なネットワークアクセスの有無を確認
- 変更されたファイルのdiffを精査するよう指示

**関連既存エントリ:** `Claude Codeのセキュリティリスク検証 — 悪意あるOSSパッケージの自動採用問題`

## 試すなら

1. 記事のプロンプトをコピーして現在のプロジェクトで実行
2. `package.json` の依存関係を確認し、最近追加されたパッケージをリストアップ
3. `CLAUDE.md` にセキュリティチェックルールを追記（パッケージ追加前にロックファイルを確認させるなど）
4. CI/CDに `npm audit` を組み込み、Claude Codeによる変更後に自動実行
