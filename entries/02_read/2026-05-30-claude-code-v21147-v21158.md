# Claude Code v2.1.147〜v2.1.158 まとめ — Opus 4.8 / dynamic workflows、`/usage` 内訳、`/code-review` 再編、background agents 安定化

## 3行要約

- v2.1.144〜146（前回エントリ [[2026-05-22-claude-code-v21144-v21146]]）以降、5/30 時点で v2.1.158 まで進行。最大の節目は v2.1.154 の Opus 4.8 対応＋dynamic workflows（→ [[2026-05-28-claude-code-dynamic-workflows]]）。lean system prompt が（Haiku/Sonnet/Opus 4.7 以前を除く）デフォルトに。
- ツール周りの再編が継続: `/simplify` はクリーンアップ専用レビュー（reuse/簡素化/効率/altitude）＋自動修正に、`/code-review --fix` は作業ツリーへ修正適用（2.1.152）。Skills/スラッシュコマンドで `disallowed-tools` をフロントマターに指定可能、`/reload-skills` 追加。`.claude/skills` 配下のプラグインがマーケットプレイス不要で自動ロード、`claude plugin init` でひな形生成（2.1.157）。
- 安定性・セキュリティ多数: `/usage` に使用量のカテゴリ別内訳（2.1.149）、PowerShell の権限回避修正・サンドボックス系修正（2.1.149/150）、background sessions/agents と worktree の不具合修正（2.1.156〜158）、WSL の画像ペースト改善、VSCode の Fast mode 表示修正など。Bash が常に exit 127 を返す回帰（2.1.147）は 2.1.148 で即修正。

## 自分への関連度: S

日常ツールの更新そのもの。特に (1) Windows / VSCode ネイティブ拡張（[[user_environment]]）に関わる修正——PowerShell 権限回避修正、VSCode/Cursor 統合ターミナルの右クリックペースト重複修正、WSL 画像ペースト、Fast mode インジケータ表示——が複数入っている点、(2) `/code-review` と `/simplify` の役割再編、(3) `/usage` のカテゴリ別内訳で Pro 枠（[[user_claude_plan]]）の消費要因が見えるようになった点が実務に効く。

### `.claude/skills` プラグインの自動ロードとは（CHANGELOG 原文で確認）

2.1.157 の該当行は以下の2つ。

> Plugins in `.claude/skills` directories are now automatically loaded, no marketplace required
> Added `claude plugin init <name>` to scaffold a new plugin in `.claude/skills`

ポイントは、**変わったのは Skill ではなく Plugin** ということ。Skill と Plugin は別物で、

- **Skill** = 単一の能力（`SKILL.md` を置いたディレクトリ）。`.claude/skills/<名前>/SKILL.md` 等は**以前から自動ロード**される。自作 Skill はこれ。
- **Plugin** = commands / agents / skills / hooks / MCP をまとめ `plugin.json` を持つパッケージ。**従来はマーケットプレイス追加 → `/plugin install` が必須**だった。

2.1.157 は「`.claude/skills` にプラグインを置くだけでマーケットプレイス不要で自動ロード」「`claude plugin init <名前>` でひな形生成」を追加した。つまり「他人のプラグインをインストールする」フローとは別に、**ローカルで自作プラグインを置いて即開発・即試用するフロー**が正式化された。

自分への意味: 単発 Skill を作るだけなら従来通り `SKILL.md` を置けば済むのでこの変更は不要。ただし「commands + skills + hooks を1パッケージにまとめたい／将来配布したい」場合は、`claude plugin init` でプラグイン構造を作り、`.claude/skills` でマーケットプレイスを介さず開発できる。**2.1.152 の `/reload-skills`（再起動なしで再スキャン）と組み合わせると、書く→リロード→確認のイテレーションが回しやすい**。自作 Skill のプラグイン化を試す入口として有用。

教訓: エントリ本文の「`.claude/skills` 配下のプラグインが自動ロード」は正確だが、「Skill の自動ロード」と読むと誤解する（Skill は元々自動ロードされる）。**対象は Plugin** という点を押さえること（[[feedback_changelog_rename_caveat]] と同系の、要約は最新原文と突き合わせる教訓）。
