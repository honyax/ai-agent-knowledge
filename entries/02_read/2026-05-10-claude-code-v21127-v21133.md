# Claude Code v2.1.127〜v2.1.133 — `--plugin-url`・worktree修正・gateway model discovery 既定OFF・MCP メモリリーク修正

## 3行要約

- v2.1.128（2026-05-04 前後）: 新規 worktree が **`origin/<default-branch>`** ではなく **ローカル HEAD** から派生するよう修正。未 push のコミットがスキップされる落とし穴を解消
- v2.1.129（2026-05-06 Code w/ Claude 当日リリース）: `--plugin-url` で `.zip` プラグインを URL から直接読み込み、`CLAUDE_CODE_FORCE_SYNC_OUTPUT=1` で同期出力を強制（Emacs eat 等の自動検出失敗対策）、Homebrew/WinGet の **`CLAUDE_CODE_PACKAGE_MANAGER_AUTO_UPDATE`** で背景アップデート、`skillOverrides` の挙動拡張、ゲートウェイ `/v1/models` 自動検出は **opt-in（`CLAUDE_CODE_ENABLE_GATEWAY_MODEL_DISCOVERY=1`）** に変更
- v2.1.132 / v2.1.133: stdio MCP のメモリリーク（長セッションで 10GB 超）修正、v2.1.110 で導入した非ストリーミング fallback リトライ上限を **撤回**（API 過負荷時に長く待つ方が outright failure より良いとの判断）、iTerm2 + tmux のターミナル表示が乱れる問題、`@` ファイル候補が非 git 作業ディレクトリで毎ターン全プロジェクトを再スキャンする問題を修正

## 自分への関連度: A

**v2.1.129 は重要なリリース**（Code w/ Claude 当日）。具体的に効くのは:
- **`--plugin-url` で URL 直読み**: チーム内でプラグイン共有がリポジトリ無しで成立するため、ナレッジベース運用で試行的にプラグインを配布できる
- **Homebrew / WinGet 背景アップデート**: Windows ユーザとして WinGet 自動更新の対象になったのは地味に大きい
- **ゲートウェイ自動検出の opt-in 化**: v2.1.126 の自動検出が v2.1.129 で env var 必須に。LiteLLM 経由運用者は `CLAUDE_CODE_ENABLE_GATEWAY_MODEL_DISCOVERY=1` の追記が必要

修正面で重要:
- **prompt cache 1時間 TTL → 5分にダウングレード** されていたバグの修正は、長セッション（自分の `/catch-up` のような重いフロー）で大きい
- **`Bash(mkdir *)` / `Bash(touch *)` の allow rule が in-project パスで効かなかった問題の修正**: 自前の Hooks 設計に直接効く
- **OAuth refresh race after wake-from-sleep** の修正は v2.1.126 の Mac sleep 系修正の続き
- **VSCode で `/clear` が会話コンテキスト・表示転写をクリアしない問題の修正**: VSCode ネイティブ拡張環境ユーザの自分には直撃

### v2.1.129（2026-05-06）

#### 新機能

- **`--plugin-url <url>`**: 指定 URL から `.zip` プラグインアーカイブを取得し、現セッションだけで使用
- **`CLAUDE_CODE_FORCE_SYNC_OUTPUT=1`**: 自動検出が外す端末（Emacs eat 等）で同期出力を強制
- **`CLAUDE_CODE_PACKAGE_MANAGER_AUTO_UPDATE`**: Homebrew / WinGet インストールの場合、背景でアップグレードコマンドを自動実行＋再起動プロンプト
- **`skillOverrides`** 設定の挙動拡張: `off`（モデルにも `/` にも非表示） / `user-invocable-only`（モデルに非表示、`/` のみ） / `name-only`（description を畳む）

#### 設定変更

- **Plugin manifest**: `themes` と `monitors` は `"experimental": { ... }` 配下に書くべき。トップレベルでも動くが `claude plugin validate` で警告
- **Gateway `/v1/models` discovery が opt-in に**: v2.1.126〜v2.1.128 の自動有効を撤回し、`CLAUDE_CODE_ENABLE_GATEWAY_MODEL_DISCOVERY=1` で明示的に有効化
- **Ctrl+R 履歴ピッカー**: デフォルトで全プロジェクト・全プロンプトを横断検索（v2.1.124 以前の挙動に戻る）。Ctrl+S で現プロジェクト/セッションに絞り込み

#### 挙動変更

- 第三者デプロイ（Bedrock / Vertex / Foundry / `ANTHROPIC_BASE_URL` ゲートウェイ）でファーストパーティ Anthropic 機能への spinner tip を表示しない
- `claude_code.pull_request.count` OTel メトリクスが MCP tool 経由 PR/MR もカウント
- ポリシー拒否エラーメッセージに **API Request ID** を含める（サポート時の特定が容易に）

#### バグ修正

- 認識されない 400 ステータスの API エラーで生 JSON を出していた問題の修正
- `/clear` がターミナルタブタイトルを reset しない
- `/rename` 後の session title chip が permission ダイアログで消える
- 子エージェント実行中に agent panel が隠れる
- 外部エディタ受け渡し（Ctrl+G）で会話履歴がブランクになる
- **`/context` が ASCII 可視化グリッドを会話に流す問題（〜1.6k token/呼び出しの浪費）**
- `/agents` Library list の矢印キー操作
- `/branch` 成功メッセージに新 branch のセッション ID が含まれない
- フルスクリーンで絵文字付き太字ヘッダの末尾が消える
- Enterprise/Team 不完全 OAuth スコープでの server-managed settings policy
- **OAuth refresh race after wake-from-sleep**
- **prompt cache 1時間 TTL が 5分にダウングレードされる**
- `/clear` / compaction 後の cache-miss 警告
- **`Bash(mkdir *)` / `Bash(touch *)` allow rule が in-project パスで honor されない**
- `deniedMcpServers` の `*://` スキーム wildcard が混在大文字小文字でマッチしない
- voice mode で WebSocket 警告が `--debug` で error として表示
- **VSCode**: `/clear` が会話コンテキスト・表示転写をクリアしない問題

## 感想・考察

### `--plugin-url` は「お試し配布」の選択肢として面白い

URL 直読みで現セッション限定使用なので、リポジトリ登録や永続インストールを経ずに「このプラグインを 1 回だけ試してみる」「チーム内で実験的に共有する」が成立する。ナレッジベース運用で気になったプラグインをサクッと試す導線として有効。

### `skillOverrides` の 3 モード拡張は今の Skill 構成に直結

`off` / `user-invocable-only` / `name-only` の 3 段階制御。特に **`user-invocable-only`** は、自作の `catch-up` / `digest` / `try` のような「ユーザーが明示的にトリガーするワークフロー Skill」に最適。

- モデルが気を利かせて勝手に発動するリスクをゼロにできる
- description がモデル context から外れて token 節約になる
- ユーザー側の `/` メニューには残るので利便性は維持

設定例（正確なキー名は v2.1.129 のドキュメント要確認）:

```json
{
  "skillOverrides": {
    "catch-up": "user-invocable-only",
    "digest": "user-invocable-only",
    "try": "user-invocable-only"
  }
}
```

`name-only` は逆に、たまに使うが description が長めの Skill（`update-config`, `simplify`, `review` 等）に向く。

### 自分の環境（Windows + VSCode ネイティブ拡張）への直撃修正

- **VSCode `/clear` が会話コンテキスト・表示転写をクリアしない問題の修正**: 普段の操作に直接効く
- **prompt cache 1 時間 TTL が 5 分にダウングレードされていたバグの修正**: `/catch-up` のような長セッションで効く
- **`Bash(mkdir *)` / `Bash(touch *)` allow rule が in-project パスで honor されない問題の修正**: 自前 Hooks に影響
- **WinGet 背景アップデート** (`CLAUDE_CODE_PACKAGE_MANAGER_AUTO_UPDATE`): 地味だが「アップデート忘れ」を防げる

### 撤回された変更にも注目

- **ゲートウェイ `/v1/models` 自動検出は opt-in に戻った**: v2.1.126 で自動化されたばかりだが、副作用が大きかったらしく env var 必須に。新機能を即時自動有効化するのではなく、安全側に倒す Anthropic の方針が見える
- **非ストリーミング fallback リトライ上限の撤回**: 「長く待つ ＞ 即失敗」という判断。エンドユーザー体感としては正しい
