# Claude Sonnet 4.6リリース & API主要変更まとめ

## 3行要約

- Sonnet 4.6がリリース（2/17）。コーディング・エージェント・専門業務でフロンティア性能。1Mトークンコンテキストウィンドウ（ベータ）対応
- Web SearchとTool Callingが正式GA（betaヘッダー不要に）。コード実行ツールがweb search/fetch併用時に無料化
- Structured Outputsが正式GA。`output_format` → `output_config.format` に移動。Data Residency制御（`inference_geo`パラメータ）追加

## 自分への関連度: A

カードゲームのAI対戦相手やゲーム内アシスタントにClaude APIを使う場合、Sonnet 4.6はコスト効率が良い選択肢。Structured Outputsの正式GAでゲームデータ（カードリスト、デッキ構成等）の構造化出力が安定する。Web SearchのGA化も、ゲーム内リサーチ機能やメタゲーム分析に活用可能。
